## 製品概要
### 背景(製品開発のきっかけ、課題等）
大学生・若者は友達と「ちょっと遊びたい」と思ったとき、LINE の DM やグループでメッセージを送らないといけない。しかし、相手の都合が合わないときに別の人を探す手間がかかる。また、返信を返す側も返信に気づかずタイムラグが発生したり、都合が合わない時に断りづらさを感じたりする。グループ内でもメンツが分からない不安がある。そのため誘う側も誘われる側にも気まずさが生じることがあり、誘いにくいという課題があります。

### 製品説明
掲示板に遊びの募集を投稿し、参加したい人がスワイプで参加できる形式のアプリです。募集には時間制限を設け、カードの外枠で残り時間を表示。参加者アイコンでメンツが分かり、イベント内のチャットで会話できます。グループを作って友達同士で募集をかけたり、QR・招待リンクで友達を追加できます。

### 特長
#### 1. スワイプで気軽に参加
主催者のアイコンを右にスワイプするだけで参加できます。参加の取り消しも左スワイプで簡単。

#### 2. 残り時間がひと目で分かる
カードの外枠が残り時間のインジケーターになり、締切間近は黄色で表示されます。

#### 3. メンツが見える
参加者のアイコンが並び、主催者アイコンの縁で集まった人数が分かります。タップで参加者詳細も確認できます。

### 解決出来ること
- DM/グループで個別に誘わずに募集・応募の形式で遊びを募れる
- 時間制限により「誘ってから返信が来るまで」のラグを解消
- 参加者が見えるので、メンツが分からない不安を解消
- グループ単位で募集をかけられる

### 競合との比較

大学生が友達を遊びに誘うときは、LINE、Instagramのストーリー、位置情報共有アプリ、ジモティーのような募集サービスが使われています。ただ、どれも「今ちょっと遊べる友達を気軽にさっと誘う」ためには作られていないので、誘う側か乗る側のどちらかが負担を感じます。

| サービス | 誘う相手 | 気軽に誘えない理由 |
|---|---|---|
| LINE | 友達 | 誘うにも乗るにも、メッセージでのコミュニケーションが必要になる。一人ずつ連絡すると返信を待つ時間がだるく、断られたり集まらなかったりすると気まずい |
| Instagramのストーリー | フォロワー | 開くまで中身がわからない。ストーリーで募集したり、それに乗ったりできる人は限られる |
| 位置情報共有アプリ | 友達 | 遊ぶときだけつながれば十分で、いつも位置を共有したい人ばかりではない。使う層が違う |
| ジモティー | 知らない人 | 知らない人と会う前提なので、友達と遊ぶ用途に合わない |

本作品では、友達やグループの中だけに見える掲示板に遊びの募集を載せます。上のサービスとは次の点が違います。

- 募集は時間が来ると消えます。人が集まらなくても募集は何も起きずに消えるので、誘った人は気にせずにすみます。
- 参加者は主催者のアイコンを右にスワイプするだけで募集に乗れます。返信の文面を考えなくてよく、最初に返事をする気まずさも減ります。
- 誰が参加しているかが見えるので、メンツや温度感を見てから決められます。
- 募集の範囲をグループ内に限れるので、知らない人や友達の友達が急に来ることはありません。
