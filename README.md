# このゆびとまれ

フッ軽遊びをもっと気軽に。LINE で誘いづらい「ちょっと遊びたい」を、募集・応募の形式で解決する Web アプリです。

## 製品概要
### 背景(製品開発のきっかけ、課題等）
大学生・若者は「ちょっと遊びたい」と思っても、LINE の DM やグループで個別に誘いづらく、返信のラグや断りづらさ、メンツが分からない不安などから遊びに誘いにくいという課題があります。

### 製品説明
掲示板に遊びの募集を投稿し、参加したい人がスワイプで参加できる形式のアプリです。募集には時間制限を設け、カードの外枠で残り時間を表示。参加者アイコンでメンツが分かり、イベント内のチャットで会話できます。グループを作って友達同士で募集をかけたり、QR・招待リンクで友達を追加できます。

### 特長
#### 1. スワイプで気軽に参加
主催者のアイコンを右にスワイプするだけで参加できます。参加の取り消しも左スワイプで簡単。

#### 2. 残り時間がひと目で分かる
カードの外枠が残り時間のインジケーターになり、締切間近は黄色で表示されます。

#### 3. メンツが見える
参加者のアイコンが並び、主催者アイコンの縁で集まった人数が分かります。タップで参加者詳細も確認できます。

### 解決出来ること
- DM/グループで個別に誘わずに募集・応募の形式で遊びを募れる
- 時間制限により「誘ってから返信が来るまで」のラグを解消
- 参加者が見えるので、メンツが分からない不安を解消
- グループ単位で募集をかけられる

### 今後の展望
- 募集の公開範囲（グループ内／友達全体）の整理
- イベント内のトークの扱いの拡充
- モバイルアプリ対応の検討

### 注力したこと（こだわり等）
* Color Pop デザインによるビビッドなカード UI
* スマホ操作前提のスワイプ参加・安全領域対応
* サーバー側での入力チェックと権限判定
