# モックでの仮決め

[仕様書](spec.md)で「不明」の点のうち、モックを動かすために仮に決めたもの。チームで決まったら仕様書を更新し、ここから消す。

## 実装に反映された仮決め一覧

| 項目 | モックでの仮決め |
|---|---|
| 募集の公開範囲 | 作成時に「全体」かグループを選ぶ。全体＝主催者の友達全員、グループ＝そのグループのメンバー。掲示板の上のタブ（全体／グループ名…）で絞り込む |
| 友達 | 相互。IDを入力（またはプロフィールの「友達申請」）すると申請になり、相手が「承認する」と友達になる。相手は拒否、自分は取り消しができる。お互いに申請したらその時点で友達になる。招待リンク（QR）は相手が渡したものなので、開いて追加するとすぐ友達になる（承認なし。申請中のものは消える）。承認前は友達と同じ扱いをしない（友達関係による募集・プロフィールの閲覧権は付かない。同じイベントの参加者どうしは従来どおり閲覧できる）（#77） |
| グループ | 作成者が友達を選んで作る。全メンバーが一覧・写真・名前・作成者の印を閲覧できる。名前・プロフィール編集と友達の追加・他人の削除は作成者だけ。誰でも自分は抜けられる。作成者が抜けたら残った最小 user_id の人へ引き継ぐ（参加時刻がないため）。最後の1人が抜けたら削除。除外・退会後は未参加のグループ募集を見られないが、既に参加中の募集の参加資格は残る（#64） |
| 人数 | 幅で募集する（例: 2〜3人、主催者を含む）。カードの「3/2〜4」＝今の人数／下限〜上限。上限に達したら参加できない。上限に達すると自動で募集終了（#44） |
| 残り時間 | 作成時に選ぶ表示時間（15/30/60/120分）。カード右下の「あと40分」と外枠の残り時間ゲージ。締切間近（10分以下）は黄（#FFD43B）（#59 #60） |
| 参加 | 左の自分の指（オレンジの線画）を右へスライドし、移動量（カード幅の1/4）の半分を越えて離すと参加（POST /events/:id/join）。途中で離すと戻る。Web・アクセシビリティのため、チャット画面の「参加する」ボタンでも参加できる。参加成功後もチャットは自動で開かない（#54 #95 #97） |
| 参加成立の演出 | 参加が成功した瞬間だけ、全画面で約3秒（2800ms）の演出（揺れ・ズーム・鳥の大群・「とまった!!」。ヒットストップなし）を流す。タップで早く閉じる。効果音・振動はプロフィールでオフにでき、初期値はオン。「視差効果を減らす」がオンなら揺れ・フラッシュ・色収差を止める。「主役は、あなた。」は出さない（#94 #102） |
| 参加の取り消し | 参加済みのカードは指先が触れた状態。自分の指を左へ戻し、移動量の半分を越えて離すと取り消し（DELETE /events/:id/join）、またはチャット画面上部メニューの「参加をやめる」。取り消しではチャットを開かない（#46 #52 #95 #97） |
| カードのタップ | カード全体をタップするとチャットが下から開く。参加していない人はチャットを読めず、「参加する」ボタンだけが出る |
| 表示時間が過ぎた募集 | 掲示板から消える。トークの一覧には「終了」として残り、チャットは読める |
| 定員に達した募集 | 上限に達したら自動で募集終了（掲示板から消え、トークに終了として残る。チャットは継続）（#44 が #33 を上書き） |
| チャット | 参加者（主催者を含む）だけ。3秒ごとに新着を取得。参加すると「〜が参加しました」が流れる |
| 友達の友達 | 参加者一覧のアイコンをタップするとその人のプロフィールが開き、友達に追加できる（同じイベントの参加者どうしなら見られる） |
| チャットを閉じる | ×ボタン、またはシートを下にスワイプ |
| 写真アイコン | プロフィールで画像を選ぶ（縮小して保存）。無ければ頭文字 |
| 通知（Web Push） | プロフィールの「通知を受け取る」で端末ごとにオン・オフ。許可はボタンを押したときだけ求める。送るのは「新しい募集（見られる人へ）」「参加（主催者へ）」「人数がそろって終了（主催者と参加者へ。主催者には参加の通知の代わりにこれを1通）」の3つで、操作した本人には送らない。タップで `/?event=<id>` を開き、掲示板でその募集のチャットを開く（ログイン前ならログイン後）。ログアウト・オフではこの端末の届け先だけ消す。iPhone はホーム画面に追加したときだけ（iOS 16.4 以降）で、それ以外は案内を出す。1人10台まで、1回の送信は45件まで（Workers のサブリクエスト上限）（#87） |

## カードの状態

見た目は X6（黒地・角丸27・660:580）で、左が自分のオレンジの指、右が主催者の白い指。移動量 travel = カード幅 × 0.25。確定のしきい値は travel の半分。横・縦とも移動 8px 未満はタップ扱いで、カード内の指の帯は縦スクロールを妨げない（Web は touchAction pan-y）。横移動が縦移動の1.5倍を超える場合だけ確定判定し、travel/2 ちょうどでは確定しない（#97）。

| 状態 | 指の位置 | できる操作 | 呼ぶ API | チャットの開き方 | 失敗・処理中の戻り方 | 備考 |
|---|---|---|---|---|---|---|
| 未参加 | 離れた位置（進み 0） | 自分の指を右へスライドし、travel/2 を越えて離すと参加。途中で離すと戻る | POST /events/:id/join | カードタップで開く。未参加は読めず「参加する」ボタン | 参加失敗は離れた位置へ戻す | 「近づいてる…」「もうすぐ…！」を指の下に出す。満員・期限切れ・処理中は操作不可 |
| 参加済み | 指先が触れた位置（進み 1） | 自分の指を左へ戻し、travel/2 を越えて離すと参加取り消し。途中で離すと戻る | DELETE /events/:id/join | カードタップで開く（読める） | 取り消し失敗は触れた位置へ戻す | WELCOME!!・鳥・「自分／主催者」を出し、取り消しではチャットを開かない |
| 主催 | 指先が触れた位置のまま動かない | 左スワイプで掲示取り消しの確認ダイアログ。確認後「取り消す」で確定 | DELETE /events/:id | カードタップで開く（読める） | 削除失敗は触れた位置へ戻す | 主催者は参加を取り消せない。参加後の WELCOME は出さない |
| 参加処理中 | 触れた位置を維持 | 指の再操作不可 | — | カードタップは可能 | 参加失敗なら離れた位置へ | joining props を正とし「参加中…」を表示 |
| 取り消し処理中 | 離れた位置 | 指の再操作不可 | — | カードタップは可能 | 失敗時は触れた位置へ戻す | leaving props を正とし「取り消し中…」を表示 |
| 掲示取り消し処理中 | 離れた位置 | 指の再操作不可 | — | カードタップは可能 | 失敗時は触れた位置へ戻す | deleting props を正とし「取り消し中…」を表示 |
| 参加失敗 | 離れた位置へ戻す | 再試行可 | — | カードタップで開く | 掲示板にエラーを表示して再試行可 | |
| 取り消し・削除失敗 | 触れた位置へ戻す | 再試行可 | — | カードタップで開く | 掲示板にエラーを表示。失敗時の自動 refresh はしない | |

## 人数リングと残り時間ゲージ

- 人数リング（主催者アイコンの縁）: 半径 44 の円周（2π×44）。開始点は 12 時（上）。時計回りに、参加人数 / 定員（count / capacity）の割合だけ白（#FFFFFF、太さ 8）で塗る。トラックは rgba(255,255,255,0.18)。主催者アバターが黒背景なので区別できる（#27 #53 #56）。
- 残り時間ゲージ（カード外枠）: 角丸長方形の周長。開始点は上辺の中央。時計回りに残り fraction（remaining / (duration_min × 60,000)）だけを表示し、時間が減ると時計回りに消えていく。現在の実装では通常は黒（#111111）、残り 10 分以下（600,000ms）は黄（#FFD43B）。トラックは rgba(0,0,0,0.10)、太さ6（#97）。

- 指先の進行ゲージ（カード下部）: 白の半透明トラック（#FFFFFF33）上にライム（#E5FF56）を描く。progress 0〜1 に追従し、描画幅の下限は5。残り時間や人数のゲージとは別（#97）。

## 初回案内と参加演出

- 初回案内は未ログイン・端末の完了記録なしの場合だけ自動表示する。5ページを横スワイプ・点・次へで移動し、スキップ／はじめるで完了を保存。ログイン画面から再表示できる。保存失敗時は再試行を促す（#99）。
- 4枚目の指先タッチと5枚目の初回表示で本番と同じ演出を流す。音は最初のタップ・スワイプ後かつ音設定オンの場合だけ。動きを減らす設定ではページ移動もアニメーションしない（#99）。
- 本番の掲示板では参加 API 成功時のみ演出し、満員に達した場合だけではない。Web は Canvas 1枚 + CSS transform、Native は Animated、2800msで終了する。「視差効果を減らす」は揺れ・フラッシュ・色収差を無効にするが、全アニメーションを止めない。効果音は Web Audio、振動は navigator.vibrate を使い、非対応なら何もしない（#94 #102）。
- 詳細は [仕様書の初回案内](spec.md#64-初回案内実装-99) と [参加成立の演出](spec.md#63-参加成立の演出実装-94-102) を参照。

## Web Push の実装補足

- ブラウザ・安全なコンテキスト・Service Worker／PushManager／Notification 対応を確認し、非対応時や鍵がない場合は案内を出す。iPhone／iPad はホーム画面からの起動を確認する。
- 新着チャット・期限切れの通知は送らない。購読鍵が変わった場合や別アカウントの届け先（409）の場合は購読し直す。送信先の404／410は削除する（#88）。
- 通知タップでは同一オリジンの既存ウィンドウを遷移してフォーカスし、なければ新しく開く。認証・閲覧権限は通常のチャットと同じ（#88）。

## 表示順

掲示板のカードは compareBoardEvents で並べる: 主催の募集を先頭、主催どうし・それ以外はそれぞれ expires_at が近い順。expires_at が同じなら元の順序を保つ。さらに BoardScreen は期限切れ（expires_at <= now）と、参加していない人にとって満員の募集を除外する（#33 #44 #50 #55）。

## 時刻の扱い

- 時・分のホイールで選択する（分は5分刻み）。新規作成の初期値は端末ローカルの現在時刻を5分単位に切り上げた時刻。候補チップ・自由入力は使わない。
- 保存時に `HH:MM〜` として time_text に保存する（ゼロ埋め2桁）。選んだ時・分が保存時点の現在の時・分より前なら翌日として `明日 HH:MM〜` にする。同じ分なら今日として扱う（秒は比較しない）。23:58 の初期値は 00:00、保存値は `明日 00:00〜`。
- 編集では保存済みの `HH:MM〜` / `明日 HH:MM〜` から時・分を復元する。以前のデータの5分刻みでない分は復元・維持でき、変更先は5分刻み。古い自由入力や空欄は現在時刻を5分単位に切り上げた値を初期値にする。翌日判定は保存時に改めて行う。
- 表示時間を変更しなければ期限は維持する（変更時のみ created_at + 新しい分数）。既存データの遡及変換はしない。
（#42 #45 #83）

## 満員の扱い

上限（capacity）に達した募集は、参加成功と同じトランザクションで expires_at を参加処理時刻に更新し、「人数がそろったので募集を終了しました」を 1 件だけ記録する。掲示板から消え（参加していない人には表示しない）、トークには終了として残り、チャットは継続できる。下限到達では終了しない。#44 が #33（満員の募集は掲示板から消える）を上書き・具体化する。
