# モックでの仮決め

仕様書（docs/spec.md）で「不明」の点のうち、モックを動かすために仮に決めたもの。チームで決まったら仕様書を更新し、ここから消す。

## 仮決め一覧

| 項目 | モックでの仮決め |
|---|---|
| 募集の公開範囲 | 作成時に「全体」かグループを選ぶ。全体＝主催者の友達全員、グループ＝そのグループのメンバー。掲示板の上のタブ（全体／グループ名…）で絞り込む |
| 友達 | 相互。IDを入力（またはプロフィールの「友達申請」）すると申請になり、相手が「承認する」と友達になる。相手は拒否、自分は取り消しができる。お互いに申請したらその時点で友達になる。招待リンク（QR）は相手が渡したものなので、開いて追加するとすぐ友達になる（承認なし。申請中のものは消える）。承認前は友達と同じ扱いをしない（友達関係による募集・プロフィールの閲覧権は付かない。同じイベントの参加者どうしは従来どおり閲覧できる）（#77） |
| グループ | 作成者が友達を選んで作る。全メンバーが一覧・写真・名前・作成者の印を閲覧できる。名前・プロフィール編集と友達の追加・他人の削除は作成者だけ。誰でも自分は抜けられる。作成者が抜けたら残った最小 user_id の人へ引き継ぐ（参加時刻がないため）。最後の1人が抜けたら削除。除外・退会後は未参加のグループ募集を見られないが、既に参加中の募集の参加資格は残る（#64） |
| 人数 | 幅で募集する（例: 2〜3人、主催者を含む）。カードの「3/2〜4」＝今の人数／下限〜上限。上限に達したら参加できない。上限に達すると自動で募集終了（#44） |
| 残り時間 | 作成時に選ぶ表示時間（15/30/60/120分）。カード右下の「あと40分」と外枠の残り時間ゲージ。締切間近（10分以下）は黄（#FFD43B）（#59 #60） |
| 参加 | 主催者の丸を右へスワイプで参加（POST /events/:id/join）。Web・アクセシビリティのため、チャット画面の「参加する」ボタンでも参加できる。参加成功後もチャットは自動で開かない（#54） |
| 参加成立の演出 | 参加が成功した瞬間だけ、全画面で約3秒の演出（ヒットストップ・揺れ・ズーム・鳥の大群・「とまった!!」）を流す。タップで早く閉じる。効果音・振動はプロフィールでオフにでき、初期値はオン。「視差効果を減らす」がオンなら揺れ・フラッシュ・色収差を止める。「主役は、あなた。」は出さない（#93） |
| 参加の取り消し | カードの主催者アイコンを左へスワイプ（DELETE /events/:id/join）、またはチャット画面上部メニューの「参加をやめる」。取り消しではチャットを開かない（#46 #52） |
| カードのタップ | カード全体をタップするとチャットが下から開く。参加していない人はチャットを読めず、「参加する」ボタンだけが出る |
| 表示時間が過ぎた募集 | 掲示板から消える。トークの一覧には「終了」として残り、チャットは読める |
| 定員に達した募集 | 上限に達したら自動で募集終了（掲示板から消え、トークに終了として残る。チャットは継続）（#44 が #33 を上書き） |
| チャット | 参加者（主催者を含む）だけ。3秒ごとに新着を取得。参加すると「〜が参加しました」が流れる |
| 友達の友達 | 参加者一覧のアイコンをタップするとその人のプロフィールが開き、友達に追加できる（同じイベントの参加者どうしなら見られる） |
| チャットを閉じる | ×ボタン、またはシートを下にスワイプ |
| 写真アイコン | プロフィールで画像を選ぶ（縮小して保存）。無ければ頭文字 |
| 通知（Web Push） | プロフィールの「通知を受け取る」で端末ごとにオン・オフ。許可はボタンを押したときだけ求める。送るのは「新しい募集（見られる人へ）」「参加（主催者へ）」「人数がそろって終了（主催者と参加者へ。主催者には参加の通知の代わりにこれを1通）」の3つで、操作した本人には送らない。タップで `/?event=<id>` を開き、掲示板でその募集のチャットを開く（ログイン前ならログイン後）。ログアウト・オフではこの端末の届け先だけ消す。iPhone はホーム画面に追加したときだけ（iOS 16.4 以降）で、それ以外は案内を出す。1人10台まで、1回の送信は45件まで（Workers のサブリクエスト上限）（#87） |

## 人数リングと残り時間ゲージ

- 人数リング（主催者アイコンの縁）: 半径 44 の円周（2π×44）。開始点は 12 時（上）。時計回りに、参加人数 / 定員（count / capacity）の割合だけ白（#FFFFFF、太さ 8）で塗る。トラックは rgba(255,255,255,0.18)。主催者アバターが黒背景なので区別できる（#27 #53 #56）。
- 残り時間ゲージ（カード外枠）: 角丸長方形の周長。開始点は上辺の中央。時計回りに残り fraction（remaining / duration_min）だけを表示し、時間が減ると時計回りに消えていく。通常は黒（#111111）、残り 10 分以下（600,000ms）は黄（#FFD43B）。トラックは rgba(0,0,0,0.10)（#27 #59 #60）。

## 表示順

掲示板のカードは compareBoardEvents で並べる: 主催の募集を先頭、主催どうし・それ以外はそれぞれ expires_at が近い順。expires_at が同じなら元の順序を保つ。さらに BoardScreen は期限切れ（expires_at <= now）と、参加していない人にとって満員の募集を除外する（#33 #44 #50 #55）。

## 時刻の扱い

- 時・分のホイールで選択する（分は5分刻み）。新規作成の初期値は端末ローカルの現在時刻を5分単位に切り上げた時刻。候補チップ・自由入力は使わない。
- 保存時に `HH:MM〜` として time_text に保存する（ゼロ埋め2桁）。選んだ時・分が保存時点の現在の時・分より前なら翌日として `明日 HH:MM〜` にする。同じ分なら今日として扱う（秒は比較しない）。23:58 の初期値は 00:00、保存値は `明日 00:00〜`。
- 編集では保存済みの `HH:MM〜` / `明日 HH:MM〜` から時・分を復元する。以前のデータの5分刻みでない分は復元・維持でき、変更先は5分刻み。古い自由入力や空欄は現在時刻を5分単位に切り上げた値を初期値にする。翌日判定は保存時に改めて行う。
- 表示時間を変更しなければ期限は維持する（変更時のみ created_at + 新しい分数）。既存データの遡及変換はしない。
（#42 #45 #83）

## 満員の扱い

上限（capacity）に達した募集は、参加成功と同じトランザクションで expires_at を参加処理時刻に更新し、「人数がそろったので募集を終了しました」を 1 件だけ記録する。掲示板から消え（参加していない人には表示しない）、トークには終了として残り、チャットは継続できる。下限到達では終了しない。#44 が #33（満員の募集は掲示板から消える）を上書き・具体化する。
